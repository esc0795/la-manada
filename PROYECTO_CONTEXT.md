# Contexto del Proyecto: Guardería y Hotel Canino

## Objetivo
Desarrollar una plataforma web para una guardería y hotel canino, inicialmente estática (MVP) con capacidad de evolución a dinámica (Reservas).

## Stack Tecnológico
- **Framework:** Astro (Modo Híbrido).
- **Estilos:** Tailwind CSS.
- **Base de Datos/Cloud:** Supabase (PostgreSQL).
- **Email:** Resend.
- **Hosting:** Cloudflare Pages.

## Fases
1. **Fase 1 (Actual):** Landing page, servicios, calculadora de tarifas (Frontend interactivo), formulario de contacto (sin BD).
2. **Fase 2:** Sistema de reservas, persistencia en Supabase, gestión de clientes y mascotas, autenticación.

## Reglas de Negocio (Fase 1)
- La calculadora debe permitir: Número de noches, tamaño del perro (Pequeño/Mediano/Grande) y número de perros.
- Call to action: WhatsApp con datos pre-llenados.
